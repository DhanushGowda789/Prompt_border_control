Set up Ollama

1. Install Ollama from ollama.com, then run ollama pull llama3.2:3b.

2. Void asks Chrome to present itself to Ollama the way Ollama expects, so this usually just works. If the test says "Ollama blocked the extension" (HTTP 403), set OLLAMA_ORIGINS to chrome-extension://* and restart Ollama:

Windows (Command Prompt): setx OLLAMA_ORIGINS "chrome-extension://*", then quit and reopen Ollama from the tray.

macOS: launchctl setenv OLLAMA_ORIGINS "chrome-extension://*", then quit and reopen the Ollama app.

Linux (systemd): run sudo systemctl edit ollama.service, add Environment="OLLAMA_ORIGINS=chrome-extension://*" under [Service], then sudo systemctl daemon-reload && sudo systemctl restart ollama.
